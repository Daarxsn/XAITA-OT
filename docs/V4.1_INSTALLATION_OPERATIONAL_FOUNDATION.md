# XAITA-OT V4.1 — Installation and Operational Foundation

## Objective

Enable an independent technical user to install XAITA-OT, verify the environment, run the CLI workflow, start the API, and confirm service health without developer assistance.

## Deliverables

- [ ] Document supported operating systems and Python versions.
- [ ] Document clean installation from source.
- [ ] Document editable/development installation.
- [ ] Add an installation verification command or script.
- [ ] Add a CLI smoke test for the documented quick-start path.
- [ ] Add an API smoke test for health/readiness and one analysis request.
- [ ] Document environment variables and configuration defaults.
- [ ] Document expected input and output formats.
- [ ] Document common installation and runtime failures.
- [ ] Ensure all verification steps run in CI.

## Acceptance criteria

1. A clean Python 3.11 environment can install the package and development dependencies.
2. A clean Python 3.12 environment can install the package and development dependencies.
3. The documented synthetic-data workflow completes successfully.
4. The documented demo workflow completes successfully.
5. The API starts using the documented command.
6. `/health` and `/ready` return successful responses.
7. A documented analysis request returns a valid structured result.
8. Verification failures provide actionable error messages.
9. Documentation is accurate when followed by an independent tester.

## Non-goals

- No redesign of completed V1, V2, or V3 functionality.
- No new detection algorithm in V4.1.
- No enterprise integration before the installation and operational path is stable.

## Completion evidence

The work is complete only when the implementation, tests, CI logs, and documentation updates are committed together and the acceptance criteria are checked off.
