# XAITA-OT V4.5 Release Readiness

## Scope

This branch contains the V4.5 release-readiness changes for installation verification, container health reporting, and dependency auditing.

## Included controls

- Installation workflow targets `v4.5-development` and validates the built wheel in a clean virtual environment.
- Docker image declares a health check against `/health`.
- Docker Compose declares a health check against `/health`.
- Dependency audit workflow targets `v4.5-development` and uploads a JSON `pip-audit` report.

## Validation status

The GitHub Actions workflows are the authoritative validation mechanism for this branch. A V4.5 release must not be marked complete until the relevant workflow runs pass on the final commit.

Required checks:

- [ ] Installation workflow passes on Python 3.11 and 3.12.
- [ ] Dependency audit workflow completes and its report is reviewed.
- [ ] Container build succeeds.
- [ ] Container health check reports healthy.
- [ ] API smoke checks pass for `/health` and `/ready`.
- [ ] No unresolved critical or high-severity dependency findings remain without an approved exception.

## Release rule

This document records release-readiness controls; it is not evidence that the checks have already passed. The release owner must attach the final workflow run links and audit artifact before merging or publishing V4.5.
