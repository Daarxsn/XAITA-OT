Benchmark methodology PROTOCOL

Split strategyGrouped stratified non-temporal split: 70% train · 15% validation · 15% test.
Leakage controlIdentical model-feature patterns are grouped into one partition before windowing.
Threshold selectionDecision thresholds are selected on validation data; the held-out test set is evaluated afterward.
ReproducibilityFive independent seeds: 42, 43, 44, 45, 46.
Memory controlWindow construction uses memory-efficient views and bounded training samples where configured.
ScopeEvidence is specific to this dataset, feature representation, split protocol, and benchmark implementation.

Research interpretation LIMITATIONS

Timestamp limitationTON-IoT Network contains no native wall-clock timestamp. Synthetic event-order semantics preserve source row order only; these results do not establish temporal generalization.
Generalization boundaryThese measurements do not establish cross-site generalization, resistance to correlated-flow leakage beyond the implemented grouping rule, or state-of-the-art performance.
